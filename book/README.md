# Book lesson: consecutive divisors

`vecinos.md` is the first runnable lesson of the Spanish Logos book. It is a
Scriptorium chapter, not a copy of Python source. The chapter is Spanish; this
note and every other public text in the repository are English.

The lesson stops at `common_divisor`. It does not add the later Euclid or
binary-search chapters.

## Replay

From a directory that has `vecinos.md`, with Scriptorium, the `logos-ai` wheel
and the `logos` checker installed:

```bash
scriptorium tangle vecinos.md
python vecinos.py
logos check --strict vecinos.logos
```

`vecinos.py` is generated by `scriptorium tangle`. Do not edit it by hand. The
generated module proves `first_fact`, `even_sum` and `common_divisor`, then
exports the strict certificate for `common_divisor`.

## What the acceptance test checks

`tests/test_book.py` tangles the page with the real Scriptorium and runs the
generated module. `tests/installed_portable.py` repeats the run from the
installed wheel and replays the certificate with the Rust checker.

The negative control changes one code line:

```python
quotient = k - j
```

The proof must fail before the certificate is written. The failure reports the
failing authored line, the expected goal, and the two equalities opened by
`p.obtain`:

```text
left:  a = d * k
right: a + 1 = d * j
```

The same values are available as machine data on
`logos.LogosProofError.details` (see `AuthoringFailure.as_dict()`), including
`kind`, `file`, `line`, `source_line`, `goal`, `opened` and `related`.

The suite also rejects a witness that mentions a symbol outside the proof
scope, and a proof that returns evidence for a different proposition.

## Package and tools

- Python package: `logos-ai`, imported as `logos` (`@logos.definition`,
  `@logos.theorem`, `@theorem.proof` with a `p` context).
- Rust checker: the `logos` executable built from `checker/`.
- Scriptorium: `scriptorium tangle` extracts every `export=` block.
