# Book lessons

The Spanish Logos book has two runnable chapters. Each is a Scriptorium source,
not a copy of Python. The chapters are Spanish; this note and every other public
text in the repository are English.

- [`vecinos.md`](vecinos.md) stops at `common_divisor`, the lemma about two
  consecutive integers. It introduces transparent divisibility, implication
  introduction, existential witnesses and the source-located failure report.
- [`euclides.md`](euclides.md) carries the argument through the least prime
  divisor, factorial positivity, factorial divisibility and Euclid's theorem
  that every integer `n >= 2` has a prime `q > n`.

The second chapter reuses the actual `divides` definition and
`common_divisor` proof from the first. It links to the first lesson through the
book navigation on this page and through the prose in the chapter.

## Replay

From a directory that has the page, with Scriptorium, the `logos-ai` wheel and
the `logos` checker installed:

```bash
scriptorium tangle euclides.md
python euclides.py
logos check --strict euclides.logos
```

`euclides.py` is generated by `scriptorium tangle`. Do not edit it by hand. The
generated module proves the named lemmas and exports the strict certificate for
`euclid`.

The first lesson follows the same three commands with `vecinos.md`,
`vecinos.py` and `vecinos.logos`.

## What the acceptance tests check

`tests/test_book.py` tangles both pages with the real Scriptorium and runs the
generated modules. `tests/installed_portable.py` repeats the runs from the
installed wheel and replays each certificate with the Rust checker.

For `euclides.md` the negative control changes one authored line:

```python
m = f
```

instead of `m = f + 1`. The lower bound `1 < m` is still true, so the proof
reaches the consecutive-divisor application. It fails there because the lemma
expects `q | f` and `q | (f + 1)`, but the altered proof has `q | f` twice. The
failure reports the lemma name, the expected antecedent, the received evidence
and the failing authored line, writes no fresh certificate, and the restored
page certifies again.

The suite also preserves the earlier `vecinos` lesson, including its sign
inversion, and rejects a witness that mentions a symbol outside the proof scope
and a proof that returns evidence for a different proposition.

## Package and tools

- Python package: `logos-ai`, imported as `logos` (`@logos.definition`,
  `@logos.theorem`, `@theorem.proof` with a `p` context).
- Rust checker: the `logos` executable built from `checker/`.
- Scriptorium: `scriptorium tangle` extracts every `export=` block.
