Logos checks portable proofs offline.

Usage:
  logos --help
  logos --version
  logos commands --json
  logos example
  logos check [--json] [--deny-custom-axioms] <FILE>
  logos inspect [--json] [--deny-custom-axioms] <FILE>

FILE is a UTF-8 .logos proof file. Use - to read standard input.
Check prints the derived statement, theory and used custom axioms.
Inspect also prints the ordered checked steps and discharged premises.
Exit codes: 0 for success, 1 for rejected input or I/O failure, 2 for usage.
The first proof fragment rejects all custom-axiom and lemma dependencies.

From an empty directory:
  logos commands --json
  logos example
  logos check --deny-custom-axioms authorization.logos
  logos inspect --json authorization.logos

To author the same proof, install Python 3.12+ and the logos-ai wheel.
Keep the Rust logos executable on PATH, then run:
  python authorization.py authored.logos
  logos check --json authored.logos
